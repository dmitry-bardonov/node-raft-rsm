# Security policy

This experimental project has no supported releases. Do not use public issues for vulnerabilities. If hosted on GitHub, use the repository's private security-advisory feature. No private email/contact was provided, so one is intentionally not invented.

Reports should include affected revision, impact, reproduction, and any suggested mitigation. Consensus safety, cross-cluster acceptance, durable-state rollback, payload disclosure, and resource-exhaustion issues are security-relevant.
